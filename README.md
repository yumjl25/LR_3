## О проекте

В данной лабораторной работе все структуры данных (Массив, Списки, Очередь, Стек, Хеш-таблицы, АВЛ-дерево), реализованные в ЛР1 и ЛР2, были переписаны в парадигме объектно-ориентированного программирования (ООП). Проект выполнен на двух языках: **C++** и **Rust**.

Для каждого класса реализованы принципы инкапсуляции (поля скрыты в `private`, доступ через `public` методы), написаны конструкторы и деструкторы (в C++), а также добавлены методы сериализации и десериализации для сохранения состояния объектов в файлы.

## Структура проекта

```text
LR3/
├── c++/                 # Проект на C++
│   ├── include/         # Заголовочные файлы классов (.hpp)

│   │   └── lib.rs       # Главный модуль библиотеки

```

## Инструкция по сборке и запуску (C++)

Для сборки проекта используется Makefile. Откройте терминал в папке `c++`.

Сборка всех тестов:

```bash
make
```

Запуск всех юнит-тестов (Catch2):

```bash
make run
```

Генерация HTML-отчета о покрытии (lcov):

```bash
make coverage
```

После выполнения откройте файл `coverage_report/index.html` в браузере.

Запуск бенчмарка (замер скорости):

```bash
make run_benchmark
```

Запуск линтера (cppcheck):

```bash
make lint
```

## Инструкция по сборке и запуску (Rust)

Для сборки используется пакетный менеджер Cargo. Откройте терминал в папке `rust`.

Запуск всех тестов:

```bash
cargo test
```

Запуск линтера (clippy):

```bash
cargo clippy --all-targets -- -D warnings
```

Запуск бенчмарка:

```bash
cargo run --release --bin benchmark
```

## Реализованные требования

* **ООП (private, public):** реализованы классы для всех структур (Стек, Массив, Очередь, Односвязный и Двусвязный списки, Хеш-таблицы (цепочки и кукушка), АВЛ-дерево).
* **Покрытие тестами более 85%:** на C++ достигнуто 100% покрытие (HTML-отчет lcov), на Rust 100% (покрытие проверено через grcov).
* **Сериализация:** в C++ реализована бинарная сериализация, в Rust текстовая.
* **Линтеры:** оба проекта проходят проверку линтерами (cppcheck и clippy) без единого предупреждения.
* **Бенчмарки:** написаны замеры скорости вставки и поиска для 100 000 элементов.
